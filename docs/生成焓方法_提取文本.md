### 2.2 全氮离子盐生成焓计算方法 {#全氮离子盐生成焓计算方法 .b63ee27f-4cf3-414c-9275-d88e3f90795e}

由于五唑离子盐是新型含能化合物，其宏量级样品从发现距今才几年。研究过程种存在历史研究数据缺乏，相关实验值无先前报导等问题。而进行实验测量又存在成本昂贵、测量周期长，无法支撑高通量筛选需求。目前生成焓实验的测量值也存在一些问题导致无法达到化学精度，比如误差线不明确、数据库二次文献存在偏差等。第一性原理计算方法是解决分子体系电子结构中的常用方法。由于其计算方法几乎不依赖于经验数，其生成焓计算结果得到了广泛的认可。

整体上，现代理论计算方法应用有一直观的规律，即在理论方法未取得质变时，在各流行使用的方法中，计算方法的计算精度往往与计算代价成反比。这一规律是研究项目选取具体方法的一种出发点------在能接受的计算代价范围内选取计算精度最高的方法，而在能接受的计算精度内选取计算代价最小的方法。密度泛函理论（DFT）计算方法很好的平衡了计算精度和计算资源消耗。

1927年，Thomas和Fermi分别各自提出，或许采用电子密度可以代替波函数用来描述体系的性质。然而，Thomas-Fermi模型仅适用于均匀电子气，其在化学上的应用是失败的。Thomas-Fermi模型求解出的电子密度较真实电子密度没有精细的壳层结构，也不能说明为何稳定的分子总能量总低于其组成单独原子的能量之和。1964年，Hohenberg和Kohn证明了两个重要的定理以确立了现代的密度泛函理论方法，而Kohn和Sham提出的Koh-Sham密度泛函理论也被广泛的应用于第一性原理计算当中。简单而言，Hohenberg和Kohn推导证明了体系的外势场和体系的基态电子密度存在一一对应关系。（Hohenberg-Kohn定理一）。非简并基态系统中，存在一个总能量泛函，当电子密度为基态电子密度时，泛函的能量为最小值(HK定理二)。通过HK定理，可以得知在给定外势场，体系的基态能量与基态电子密度均存在对应关系。只要找到总的能量泛函，便可以通过能量最小化得到体系的基态能量。通常（10000K以下）温度对于电子结构的影响很小。因此基态密度泛函理论可以满足绝大多数物性的模拟。然而HK定理并没有明确的给出总能量泛函。而Kohn和Sham提出的通过引入

一个参考的无相互作用的辅助系统，给出了总能量泛函的表达式。从而成功的将密度泛函理论应用于真实材料的模拟

KSDFT的总能表达式如下所示：

$$E\left\lbrack \rho \right\rbrack = T_{s}\left\lbrack \rho \right\rbrack + J\left\lbrack \rho \right\rbrack + \int_{}^{}{V\left( \mathbf{r} \right)\rho\left( \mathbf{r} \right)d\mathbf{r} + E_{\text{xc}}\left\lbrack \rho \right\rbrack}\text{\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ }(2.2.1)$$

其中电子总能构成为依次为动能、库伦能、外势能和交换关联能。其中动能项通过求解辅助系统的Kohn-Sham方程获得。交换关联项代表Kohn-Sham密度泛函理论动能项和电子间经典库仑相互用与精确的多体相互作用的差值，一般近似成一个能量泛函。由于交换关联相互作用是Kohn-Sham密度泛函理论中唯一的近似，因此密度泛函理论的精度主要受交换关联近似影响。然而，交换关联的泛函发展至今出现了许多近似方法，分为局域密度近似（LDA）、广义梯度近似（GGA）和超广义梯度近似（meta-GGA，含密度梯度和动能密度的交换-相关能泛函）和引入精确的交换相互作用的杂化泛函，以及双杂化泛函。Hartree-Fock方法可以提供精确交换能，在杂化泛函的计算中可以混合一定比例的Hartree-Fock交换能从而精确的描述交换关联相互作用。而双杂化泛函在杂化泛函的基础上考虑了MP2关联。上述密度泛函理论的精度层级可参考如图11所示的雅各布天梯。

#### 2.2.1 阴阳离子气相生成焓计算  {#阴阳离子气相生成焓计算 .list-paragraph .566ba9ff-a5b0-4b6f-bbdf-c3ab41993fc2}

根据定义，标准状态的各元素最稳定单质的生成焓为0，因此理论计算中所规定的各物质绝对能量在生成焓的计算中意义不大，此外无法通过仅对化合物的计算确定其生成焓。根据盖斯定律，不妨先设定一种物质生成焓的定义：

$$\mathrm{\Delta}H_{\text{calc}} = H_{obj,calc} - \sum_{i}^{}H_{com,calc,i}\text{\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ }\ \text{\ \ \ \ \ \ \ \ \ \ \ \ \ \ }\text{\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ }\ \ \ \ \ \ (2.2.1.1)$$

于此，H~obj,calc~可以理解为目标化合物计算总焓，H~com,calc,i~是指将目标化合物分解为一系列组分物质"com"后，第i个物质的计算总焓。暂以一种近似的手法看待该ΔH~calc~，认为该ΔH~calc~与实验值相等，那么根据生成焓的定义：

$$\mathrm{\Delta}H_{f} = H_{f,obj} - \sum_{i}^{}H_{f,sub,i}\text{\ \ \ \ \ \ \ \ \ \ \ \ }\text{\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ }\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ (2.2.1.2)$$

而由于单质的生成焓定义为0，则：

$$\mathrm{\Delta}H_{f} = H_{f,obj}\text{\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ }\text{\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ }\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ (2.2.1.3)$$

若以实验的测量方法，使物质不与单质做差，而是与上述理论计算ΔHcalc生成同样的组分，则定义ΔH~exp~:

$$\mathrm{\Delta}H_{\exp} = H_{obj,exp} - \sum_{i}^{}H_{com,exp,i}\text{\ \ \ \ \ \ \ }\text{\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ }\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ (2.2.1.4)$$

上述ΔH~calc~、ΔH~exp~仅是根据能量的方式定义的，于此，根据盖斯定律，给予上述ΔH~exp~生成焓的定义，则：

$$\mathrm{\Delta}H_{f,exp} = H_{f,obj,exp} - \sum_{i}^{}H_{f,com,exp,i}\text{\ \ \ \ \ \ \ }\text{\ \ \ \ \ \ \ \ \ \ \ \ }\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ (2.2.1.5)$$

可近似地认为，ΔH~calc~与ΔH~f,exp~相等，则

$$H_{obj,calc} - \sum_{i}^{}H_{com,calc,i} = H_{f,obj,exp} - \sum_{i}^{}H_{f,com,exp,i}\text{\ \ }\text{\ \ \ \ \ \ \ \ \ \ }(2.2.1.6)$$

显然，上式可以通过移项形成下式：

$$H_{f,obj,exp} = \sum_{i}^{}H_{f,com,exp,i} - \sum_{i}^{}{H_{com,calc,i} + H_{obj,calc}}\text{\ \ \ \ \ \ \ \ \ \ }\left( 2.2.1.7 \right)$$

是建立在ΔH~calc~与ΔH~f,exp~相等的条件下的，即：计算总焓之差可以看作与实验值生成焓之差近似相等。通过这种方式，可以在等式左侧的数据H~f,obj,exp~未取得观察值时，通过右侧已知的片段能量H~f,com,exp,i~和可计算的H~com,calc,i~、H~obj,calc~的加和，可以计算出H~f,obj,exp~。

若能接受该条件，则可以进入以下推广。当分割的片段完全不划分时：

$$H_{f,obj,exp} = H_{f,obj,exp} - H_{obj,calc} + H_{obj,calc} = H_{f,obj,exp}\ \ \ \ \ \ \ \ \ \ \ (2.2.1.8)$$

该等式是恒成立的，其应用意义为：目标化合物分子生成焓可查时，直接查用了目标化合物分子的生成焓。而当分割的片段恰好为各单质时：

$$H_{f,obj,exp} = 0 - \sum_{i}^{}{H_{com,calc,i} + H_{obj,calc} =}H_{obj,calc} - \sum_{i}^{}H_{com,calc,i}\ \ (2.2.1.9)$$

此时，等式的右侧为生成焓的标准定义，只是各部分生成焓的能量来自于计算值。该等式建立于ΔH~calc~与ΔH~f,exp~相等，则这种情况的应用意义为实验的生成焓与理论的生成焓相等，即回归到了假设上，也是恒成立的。

将各种片段划分为单质其本身是一种理想的方案，然而在实际的应用中，物质单质并不一定易于建模与计算。对于石墨等单质为晶体的元素，其生成焓的计算需要固体物理计算软件处理。而分子型物质的计算通常需要量子化学计算软件处理。因此，需要采用不同的策略对目标化合物分子进行片段的划分，以确保各片段的实验值数据可查，并且使ΔH~calc~与ΔH~f,exp~相等的假设尽可能正确。对于阴阳离子气态生成焓，在此拟采用原子化能方法。

原子化能是一种常用的生成焓计算方法，是最能保证上问所提及的片段分割中所分割出的片段具有可查阅实验值的方法。原子化能方法的操作实质在于将目标化合物完全分割为各元素的单原子，并在计算完原子化能计算值后，将这个数值直接加到各元素单原子焓实验值上。NIST网络化学手册中CHNOLi原子生成焓实验值分别为171.29、52.103、112.97、59.555和38.074
kcal/mol。对于CHNOLi化合物而言，该方法可以用下式进行表达：

$${\mathrm{\Delta}H}_{f,p}\left( C_{a}H_{b}N_{c}O_{d} \right) = \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ $$

$H_{\text{calc}}\left( C_{a}H_{b}N_{c}O_{d} \right) + \ \left\lbrack \text{a\ b\ c\ d} \right\rbrack \bullet \begin{bmatrix}
{\mathrm{\Delta}H}_{f,exp}\left( C \right) - H_{\text{calc}}\left( C \right) \\
{\mathrm{\Delta}H}_{f,exp}\left( H \right) - H_{\text{calc}}\left( H \right) \\
{\mathrm{\Delta}H}_{f,exp}\left( N \right) - H_{\text{calc}}\left( N \right) \\
{\mathrm{\Delta}H}_{f,exp}\left( O \right) - H_{\text{calc}}\left( O \right) \\
{\mathrm{\Delta}H}_{f,exp}\left( \text{Li} \right) - H_{\text{calc}}\left( \text{Li} \right) \\
\end{bmatrix}\text{\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ }\text{\ \ \ \ \ \ \ \ \ \ \ \ \ }\ \ \ \ \ (2.2.1.10)$

在具体的操作流程上，在原子化能的计算过程中需要确认焓值的构成。大多数的原子化能方法是基于静态结构的，而静态结构的自洽计算结果并不能够直接用于上式，而需要增加零点能等修正数值。而对于各直接优化的计算方案，则可以直接读取修正后的生成焓。

为确保计算水平的横向可对比性，拟采用原子化能方案进行计算。因此，随上述任务同时进行计算的还应有C、H、N、O、Li单原子的计算。在单原子计算的实际过程中，需注意为其修改多重态数。对应C原子应修改为3，H原子为2、N原子为4、O原子为3、F原子为2、Li原子为2。这些单原子的计算应当通过单点计算完成，并加和固定数值0.00236
hartree的修正。确保所有的输出结果皆为正确收敛计算的输出结果后，需针对不同的计算进行输出文件焓的提取。

对于单点计算，需提取自洽场能。由于计算过程中不包含振动分析，所以需要采用提取单点计算的焓值加热矫正的方法进行实际总焓的估值。于此，若在各单点计算对应水平下进行振动分析将引入大量的计算量，与采用单点计算减少计算量的目的南辕北辙。由于计算于不同计算水平的热力学焓矫正值往往差别甚小，因此可以选择低水平水平的热力学焓矫正值进行矫正。由此，单点计算的生成焓在某一计算水平下可以由以下部分组成：目标化合物分子于该计算水平的自洽场能H~SCF,obj~、目标物质于RIJCOSX-B3LYP/def2-SVP下的热力学含矫正值ΔH~corr,obj~、各单原子的自洽场能H~SCF,SA~、各单原子的统一热力学校正值ΔH~corr,SA~、各单原子的气相生成焓实验值H~f,exp,SA~。

具体而言，按以下表达式：

$$\text{\ \ \ }H_{f,\text{prediction}} = H_{SCF,obj} + {\mathrm{\Delta}H}_{\text{corr},\text{obj}} + \sum_{i}^{}{(H}_{f,\exp,\text{SA},i} - H_{SCF,SA,i} - {\mathrm{\Delta}H}_{\text{corr},\text{SA},i})\ \ \text{\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ }\ (2.2.1.11)$$

其中，H~f,exp,SA~由数据库查阅获得，而其它各项由计算获得。

对于直接结构优化计算，由于计算过程中本身包含振动分析，可以直接提取修正后的目标化合物分子总焓，即单点能计算中的H~SCF,obj~项与ΔH~corr,obj~可以合并为H~obj~项直接提取出来。因此，目标化合物分子预测值的表达式可以按下式表达：

$$\text{\ \ \ \ }H_{f,\text{prediction}} = H_{\text{obj}} + \sum_{i}^{}{(H}_{f,\exp,\text{SA},i} - H_{SCF,SA,i} - {\mathrm{\Delta}H}_{\text{corr},\text{SA},i})\ \ \ \ \text{\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ }(2.2.1.12)$$

对比于单点能计算，直接结构优化计算所需消耗的机时更长，所需人工检查的部分也更多。在直接结构优化计算的过程中，需要不断检查结构是否正常优化收敛且不具有虚频。

在RIJCOSX-B3LYP/def2-SVP优化的结构基础上，采用更高计算水平进行单点能计算。本研究采用的DFT测试方法有：基于广义梯度近似（GGA）的纯泛函PBE；基于超广义梯度近似（mGGA）的纯泛函B97M-V和SCAN；GGA杂化泛函B3LYP；域分离杂化泛函wB97X；mGGA杂化泛函M06-2X；双杂化泛函B2PLYP、DSD-BLYP和wB97X-2。DFT方法计算采用def2-TZVP基组，不采用密度拟合。采用基于波函数的post-HF测试方法有：DLPNO-F12-CCSD(T)和DLPNO-CCSD(T)/CBS。另外还采用组合方法G4进行测试。

DLPNO-F12-CCSD(T)采用了主要局域自然轨道对相关能进行近似计算，F12考虑了相关能的函数关系。基组方面除了cc-pVDZ-F12，还采用了两个辅助基组cc-pVTZ/C和cc-pVDZ-F12-CABS。DLPNO-CCSD(T)/CBS采用了主要局域自然轨道对相关能近似，目标精度为CCSD(T)/
cc-pCV∞Z，具体计算方法如下：

（1）HF/CBS计算

$$\text{\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ E}\left( X \right) = E\left( \infty \right) + Ae^{- \alpha\sqrt{X}}\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ (2.2.1.13)$$

其中α=4.420

G4方法采用B3LYP优化和频率计算，后续单点能采用HF、MP2、MP4和CCSD(T)等方法进行基组外推。其post-HF计算采用基组较小，比CCSD(T)用cc-pVDZ和cc-pVTZ完备基组外推代价小。计算基准采用ccCA组合方法，目标精度为CCSD(T,Full)/aug-cc-pCV∞Z，具体计算方法如下：

（1）在wB97X/def2-TZVP水平下进行结构优化和频率计算，ZPE矫正系数为0.970。

（2）计算MP2/CBS水平单点能

$$E\left( X \right) = E\left( \infty \right) + Ae^{- \left( X - 1 \right)} + Be^{- \left( X - 1 \right)^{2}}\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ (2.2.1.17)$$

$E\left( \frac{MP2}{aug - cc} - pV\infty Z \right) = \text{\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ }$

$$\mathrm{\Delta}E\left( \text{CV} \right) = E\left\lbrack \frac{MP2\left( \text{Full} \right)}{aug - cc} - pCVTZ \right\rbrack - E\left( \frac{MP2}{aug - cc} - pVTZ \right)\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ (2.2.1.20)$$

（5）计算ccCA-CBS能量

$$E\left( ccCA - CBS \right) = E\left( \frac{MP2}{aug - cc} - pV\infty Z \right) + \mathrm{\Delta}E\left( \text{CC} \right) + \mathrm{\Delta}E\left( \text{CV} \right) + \mathrm{\Delta}E\left( \text{ZPE} \right)\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ (2.2.1.21)$$

（6）最后加入wB97X/def2-TZVP水平不含ZPE的焓矫正能

#### 2.2.2 晶格焓计算 {#晶格焓计算 .list-paragraph .566ba9ff-a5b0-4b6f-bbdf-c3ab41993fc2}

晶格焓体现了离子之间的相互作用的贡献，可表示为：

$$\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \mathrm{\Delta}H_{L} = U_{\text{POT}} + \left\lbrack p\left( nM/2 - 2 \right) + q\left( nX/2 - 2 \right) \right\rbrack\text{RT}\ \ \ (2.2.2.1)$$

其中U~POT~为晶格能；nM和nX由离子结构性质决定，单原子取3，线性多原子取5，非线性多原子取6；R为理想气体常数；T为开尔文温度。对于本研究LI取值3，其它离子都取值6。

采用VBT（基于体积理论）计算U~POT~（kJ mol^-1^）。

当U~POT~ \< 5000 kJ mol^-1^时，

$$\text{\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ }U_{\text{POT}} = 2I(\alpha/V_{m}^{\frac{1}{3}} + \beta)\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ (2.2.2.2)$$

其中I为晶格离子强度系数，V~m~分子式单位体积，系数α（kJ mol^-1^
nm）和β（kJ mol^-1^）是和阴阳离子比率有关。本体系中**I = 1，**α =
117.3，**β =** 51.9。V~m~的计算通常采用电子密度在0.001 electron
Bohr^-3^等值面包围的体积，详见晶体密度计算中的分子体积法。

当U~POT~ \> 5000 kJ mol^-1^时，

$$\text{\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ }U_{\text{POT}} = AI(2I/V_{m}^{\frac{1}{3}})\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ (2.2.2.3)$$

其中A = 121.4 kJ mol^-1^。

分子体积的计算采用电子密度在0.001 electron
Bohr^-3^等值面包围的体积。采用用蒙特卡洛法计算体积时，Bohr^-3^随机采样点数设为5000。

### 5. 测试原理 {#测试原理 .b63ee27f-4cf3-414c-9275-d88e3f90795e}

为测试开发的离子型全氮或富氮含能材料生成焓计算方法，需以计算的材料生成焓与实验标准值的偏差值作为基准，计算公式如下：

$$\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \sigma = \sum_{i}^{N}{\left| y_{i}^{\text{pred}} - y_{i}^{\text{std}} \right|/N}\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ (2)$$

其中*y*^pred^为采用发展的计算模型计算的预测值（ΔH~f~\[(M^p+^)~q~(X^q-^)~p~,
cr\]），*y*^std^为标准值，σ为测试平均绝对值偏差。以上计算标准为公认的根据平均绝对误差定义所提出的公式。

在实验上，将一定质量的被测药剂在充氧气的量热弹内被引燃，以水为测温介质，在恒温状态下测定量热计中内桶水的温升值，根据热平衡原理，计算单位质量被测药剂的燃烧热，采用此原理测定生成焓标准值。

参照GJB
5891.29-2006方法，采用自动量热仪对待测药剂进行燃烧热测试，测试步骤如下：

1.依次接通各部件的电源开关，其顺序为：量热计-点火电源-打印机-显示器-计算机主机。

2.进入自动量热仪测试主界面，预热30min。

3.根据试样的物理化学性质，调整点火电压和点火时间。

4.给量热计外桶补足蒸馏水，将量热计的外桶水调节至与室温相同。

5.单击"仪器测试"按钮，然后点击"搅拌"和"点火"，检查仪器搅拌及点火功能是否正常。

6.称取经干燥后的待测药剂（起爆药、击发药约1
g，点火药、烟火药和曳光药等约2 g），精确至0.0002 g。

7.将弹头放在环形铁架上，把坩埚放入弹头电极杆下端的环内。

8.取镍铬电阻合金丝约100 mm\~120 mm，两端分别与电极杆连接，并卡紧。

9.将镍铬电阻合金丝中部直接放入坩埚内，并埋入试样。

10.将弹头放入弹杯内，盖上弹帽，并拧紧。

11.将氧弹针形阀与充氧导管连接，拧开针形阀，拧开氧气瓶总阀，调节调压阀，缓慢往弹内充入氧气，直至弹内压力为3.0
MPa时，保持15s，依次关闭针形阀、调压阀和氧气瓶总阀，拧上弹顶帽。

12.给量热计内桶注入蒸馏水，调节内桶水温，利用量热仪计量内桶水体积测量程序进行操作。

13.提起量热计上盖，将点火电极插入上盖的插孔中，将内桶放入量热计中，再将氧弹放入内桶，盖上上盖

14.单击计算机量热仪测试软件主界面的"测量"按钮，在弹出的对话框中单击"物质燃烧值"按钮，测试系统恢复至主界面。

通过测定得到的定容燃烧热，以及燃烧产物的生成焓，可根据盖斯定律精确得出被测样品的生成焓。计算方法如下：

$$\text{\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ }\sum_{}^{}{n_{\text{mi}}\mathrm{\Delta}_{f}H_{\text{mi}}^{\theta} = \sum_{}^{}{n_{\text{pi}}\mathrm{\Delta}_{f}H_{\text{pi}}^{\theta} - Q_{p}}}\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ (3)$$

$$\text{\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ }Q_{V} = Q_{p} + 2.477n\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ (4)$$

式中：Q~p~为定压燃烧热，kJ/kg；Q~V~为定容燃烧热，kJ/kg；n~pi~为燃烧产物中i组分的物质的量，mol/kg；$\Delta_{f}H_{\text{pi}}^{\text{θ}}$为燃烧产物中i组分的生成焓，kJ/mol；n~mi~为z炸药中i组分的物质的量，mol/kg；$\Delta_{f}H_{\text{mi}}^{\text{θ}}$为炸药中i组分的生成焓，kJ/mol；n为燃烧产物中所有气体的物质的量，mol。

密度泛函理论（DFT）方法是采用DFT优化盐的晶体结构，并获得总能。然后，采用相同水平的DFT优化隔离体系的离子结构，并获得总能。则晶格能可通过以下方式计算：

$$\text{\ \ \ \ \ }U_{\text{POT}} = \left\{ \text{qE}\left\lbrack \left( M^{p +} \right),g + pE\left\lbrack \left( X^{q -} \right),g \right\rbrack \right\rbrack \right\} - E\left\lbrack \left( M^{p +} \right)_{q}\left( X^{q -} \right)_{p},cr \right\rbrack\ \ \ \ \ \ (10)$$

test1.gjf和test2.gjf分别为**1a**和**1c**的G4方法的计算文件。test1.gjf和test2.gjf中均设置占用32核心和64GB内存的计算资源。test1.gjf中设置**1a**的电荷为-1和自旋多重度为1。test2.gjf中设置**1c**的电荷为1和自旋多重度为1。将test1.gjf和test2.gjf分别上传至Gridview的Gaussian
Portal中进行作业调度和计算，界面如下：

![](./_media/media/image11.png){width="5.904861111111111in"
height="4.323611111111111in"}

G4是一种混合计算方法。在B3LYP/GTBas3水平下进行结构优化和振动频率计算，获得振动能E~vib~、平动能E~trans~和转动能E~rot~，再经过一系列基组外推获得修正后包含核间排斥势的电子总能E~total~，体系内能*U*由以下四部分组成：

$$\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ U = E_{\text{total}} + E_{\text{vib}} + E_{\text{trans}} + E_{\text{rot}}\text{\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ }\left( 2 \right)$$

体系内能*U*与焓*H*之间的关系为：

$$\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ H = U + k_{b}\text{T\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ }\left( 3 \right)$$

其为*k*~B~*T*（*k*~B~为玻尔兹曼常数，*T*为开尔文温度取值298.15
K）。实际操作提取Gaussian软件的log输出文件中"G4
Enthalpy="后的数值（单位为Hartree，kcal/mol的转换因子为627.51）。test1.log提取的数值为-273.664407。test2.log提取的数值为-112.120023。

kcal/mol。G4计算水平二重态H和四重态N单原子的焓分别为-0.49906和-54.571306
Hartree。将原子化反应的代入可得气态生成焓，如下所示：
